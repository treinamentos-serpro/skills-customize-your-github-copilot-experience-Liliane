
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construir um jogo da Forca em Python para praticar manipulação de strings, loops, condicionais, entrada de dados e seleção aleatória.

## 📝 Tarefas

### 🛠️ Implementar o jogo da Forca

#### Descrição

Complete o arquivo `starter-code.py` para criar um jogo em que o jogador deve adivinhar uma palavra oculta informando uma letra por vez. A palavra deve ser escolhida aleatoriamente a partir da lista fornecida.

#### Requisitos

O programa concluído deve:

- Selecionar uma palavra aleatoriamente da lista predefinida.
- Aceitar palpites de letras e exibir o progresso atual da palavra no formato `_ _ _`.
- Registrar as letras já informadas e evitar que o mesmo palpite seja contado mais de uma vez.
- Controlar o número de tentativas incorretas restantes.
- Encerrar quando o jogador adivinhar a palavra ou quando as tentativas incorretas acabarem.
- Exibir uma mensagem informando se o jogador venceu ou perdeu.
